📦 ControlaFácil
O ControlaFácil é um sistema de gestão inteligente desenvolvido como projeto acadêmico para o 4º semestre do curso de Análise e Desenvolvimento de Sistemas (USCS). O foco da aplicação é facilitar o controle de estoque e a gestão condominial, unindo praticidade e uma interface moderna.

🚀 Tecnologias Utilizadas
O projeto utiliza uma arquitetura separada entre cliente e servidor:

FrontEnd: Construído com Vite, React e Tailwind CSS para uma interface rápida, responsiva e performática.

Backend: Desenvolvido em Node.js com framework Express, focado em uma API escalável.

Banco de Dados: Utiliza MySQL para persistência e integridade dos dados.

🛠️ Como Iniciar a Aplicação
Para rodar o projeto localmente, siga os passos abaixo:

1. Clonar o Repositório
Bash
git clone https://github.com/ControlaFacil/ControlaFacil.git
cd ControlaFacil
2. Configurar e Iniciar o FrontEnd
Abra o terminal na pasta raiz e execute:

Bash
cd FrontEnd
npm install
npm run dev
Acesse o link gerado (geralmente http://localhost:5173) no seu navegador.

3. Configurar e Iniciar o Backend
Em um novo terminal, a partir da raiz:

Bash
cd Backend
npm install
npm run dev


📂 Organização do Projeto
/FrontEnd: Código-fonte da interface, componentes e estilização.

/Backend: Regras de negócio, rotas da API e integração com banco de dados.

/.vscode: Configurações de ambiente de desenvolvimento.
